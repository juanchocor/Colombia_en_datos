## ¿Qué es Colombia en Datos?

**Colombia en Datos** es un proyecto de divulgación científica y ciencia de datos que busca analizar fenómenos sociales, económicos, ambientales y políticos utilizando información pública, metodologías transparentes y herramientas de análisis de datos.

El objetivo no es confirmar opiniones preconcebidas, sino formular preguntas, construir hipótesis y contrastarlas con evidencia.

Cada episodio corresponde a una investigación independiente, documentada desde la obtención de los datos hasta la publicación de los resultados.

---

# Objetivos

- Promover el pensamiento crítico basado en evidencia.
- Divulgar ciencia de datos aplicada a problemas reales de Colombia.
- Construir investigaciones completamente reproducibles.
- Facilitar que cualquier persona pueda replicar los análisis en su ciudad, municipio o región.
- Crear una comunidad interesada en comprender Colombia mediante datos.

---

# Filosofía del proyecto

Los datos, por sí solos, no explican la realidad.

Tampoco buscan demostrar una postura política o ideológica.

Cada investigación parte de una pregunta, plantea una hipótesis y analiza la evidencia disponible para intentar responderla, reconociendo siempre las limitaciones de los datos utilizados.

En este proyecto:

- La correlación no implica causalidad.
- Las conclusiones siempre dependen de la calidad de los datos.
- Las limitaciones forman parte del análisis.
- Toda afirmación debe estar respaldada por evidencia.

# Metodología

Cada investigación sigue el mismo flujo de trabajo:

1. Definición del problema
2. Revisión de literatura científica
3. Formulación de hipótesis
4. Recolección de datos
5. Validación de la calidad de las fuentes
6. Limpieza y transformación
7. Análisis exploratorio
8. Modelado estadístico
9. Visualización
10. Interpretación de resultados
11. Discusión de limitaciones
12. Divulgación del resultado

---

# Principios del proyecto

Este proyecto se rige por cinco principios:

- Transparencia
- Reproducibilidad
- Rigor metodológico
- Acceso abierto
- Honestidad intelectual

Cuando la evidencia no sea suficiente para responder una pregunta, se dirá explícitamente.

# Datos

Todos los datos utilizados provienen de fuentes públicas o de libre acceso.

- DNP
- MinTIC
- Ministerio de Educación Nacional

- SISPRO
- IDEAM
- SIATA
- Registraduría Nacional
- Datos Abiertos Colombia

Cada episodio documenta detalladamente:

- Fuente
- Año
- Cobertura
- Variable utilizada
- Nivel de confiabilidad
- Posibles limitaciones

# Reproducibilidad

Todos los análisis pueden reproducirse siguiendo los notebooks incluidos en cada episodio.

Los datos originales nunca se modifican.

Toda transformación queda documentada.
