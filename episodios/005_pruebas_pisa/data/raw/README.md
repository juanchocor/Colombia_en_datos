# Datos originales

Este directorio guarda los archivos fuente originales del episodio de Pruebas PISA.

## Formato de documentación

Para cada archivo se recomienda registrar:

- Fuente
- Nombre del archivo
- URL o referencia
- Fecha de descarga
- Periodo cubierto
- Descripción
- Observaciones relevantes

## Ejemplo

```text
- Fuente: OECD / PISA
- Nombre: pisa_2022.csv
- URL: https://...
- Fecha de descarga: YYYY-MM-DD
- Periodo: 2022
- Descripción: Datos de desempeño y contexto de estudiantes en PISA.
- Observaciones: Revisar metadatos y variables de ponderación.
```

> Los archivos originales no se suben al repositorio y deben mantenerse locales.
