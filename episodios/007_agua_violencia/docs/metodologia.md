# Metodologia inicial

## Pregunta y escala

El estudio de Bogota permite discutir una situacion temporal, urbana y con diseno causal. Este episodio construye una lectura territorial descriptiva de Colombia. Las dos escalas no deben presentarse como si respondieran la misma pregunta.

## Variables

La primera version se limita a tres dimensiones:

- cobertura de acueducto;
- calidad o riesgo del agua;
- ausencia de cobertura.

Cada indicador debe conservar su definicion oficial, ano, denominador y unidad geografica.

## Integracion

La integracion se hara mediante codigo DIVIPOLA cuando este disponible. Antes de producir resultados se verificara:

- unicidad del codigo territorial;
- duplicados;
- municipios sin correspondencia;
- valores faltantes;
- consistencia del periodo;
- cambios de nombre o codigo territorial;
- comparabilidad de denominadores.

## Interpretacion

El analisis puede identificar concentraciones, diferencias y asociaciones espaciales. No puede demostrar que una condicion de acceso al agua cause violencia u otra consecuencia social. Las consecuencias sociales se contextualizaran mediante investigaciones existentes.
