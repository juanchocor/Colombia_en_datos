# Datos originales

Los archivos descargados de fuentes externas se conservan localmente, son de solo lectura y no se suben al repositorio.

Para cada fuente documentar:

- institucion responsable;
- nombre del dataset o archivo;
- URL o referencia del servicio;
- fecha de consulta o descarga;
- periodo de los datos;
- unidad geografica y unidad de observacion;
- definicion de las variables utilizadas;
- codigo territorial, si existe;
- filtros y transformaciones aplicados;
- observaciones sobre comparabilidad y calidad.

Los datos procesados necesarios para reproducir el analisis deben guardarse en `data/processed/` cuando su tamano sea razonable.
