# Datos originales

Los archivos descargados de fuentes externas son locales, de solo lectura y no deben subirse al repositorio.

Para reproducir el análisis, documentar aquí cada fuente con:

- fuente original y URL de descarga;
- fecha de descarga;
- archivo original utilizado;
- transformaciones, variables seleccionadas y filtros;
- unidad de análisis y periodo cubierto.

Los datos procesados que sean necesarios para reproducir el análisis deben guardarse en `data/processed/` y tener un tamaño razonable.
