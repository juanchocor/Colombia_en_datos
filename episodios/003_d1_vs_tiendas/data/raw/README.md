# Datos originales

Los archivos descargados de fuentes externas se conservan localmente, son de solo lectura y no deben subirse al repositorio.

Para cada fuente, documentar:

- entidad responsable y URL de descarga;
- fecha de descarga;
- nombre del archivo original;
- descripción, periodo y unidad de análisis;
- transformaciones, variables seleccionadas y filtros aplicados.

Los datasets necesarios para reproducir el análisis, cuando tengan un tamaño razonable, deben guardarse en `data/processed/`.
