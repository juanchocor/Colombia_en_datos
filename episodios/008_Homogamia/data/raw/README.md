# Datos originales

Este directorio contiene los archivos fuente locales del Censo Nacional de Población y Vivienda 2018. Organiza los archivos por departamento dentro de `censo_2018/` cuando se confirme la distribución descargada.

Para cada fuente registra:

- Institución y operación estadística.
- Nombre y formato del archivo.
- URL o referencia de descarga y fecha de consulta.
- Periodo y cobertura territorial.
- Diccionario asociado y versión.
- Observaciones sobre estructura, codificación y restricciones de uso.

Los microdatos no se versionan ni se copian a `interim/` o `processed/` si conservan información personal. No incluyas aquí archivos con datos reales en Git.
